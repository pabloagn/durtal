## Overview

Part of SLN-382 (staged activation). The perfume collection was fully built on main (model SLN-356, services SLN-357, home, detail and editing SLN-366) but stayed closed: `/perfumes` answered 404 on :3100, no menu named it, and the database refused every perfume row. This task opens it.

Why Joris saw nothing (checked 2026-10-04):

- `WORK_DOMAINS.perfume.enabled` was `false` (`src/lib/catalogue/domains.ts`). Every perfume route layout calls `requireEnabledDomain`, so every page answered 404, and navigation lists only open collections.
- `works_kind_enabled_check` was `kind = 'book'`. Even with the switch on, creating a perfume would have failed.
- No migration was missing: the live journal has every migration up to `0052_app_settings`, and all perfume tables exist with 0 rows.

## Implementation Details

- `src/lib/catalogue/domains.ts`: `perfume.enabled: true`. Navigation, the Go and Add menus, the command palette, the dashboard, the collection switch and Settings › About read this switch, so they now name Perfumes.
- `src/lib/db/schema/works.ts`: `works_kind_enabled_check` is `kind IN ('book', 'perfume')`.
- `src/lib/db/migrations/0053_open_perfumes.sql` (generated by `drizzle-kit generate`): drops and re-adds the check with the new list. It changes no row.
- The write services do not read the switch, so the check is the only write guard. Each collection widens it in the change that turns its own switch on. `work-kind-migration.test.ts` keeps the two equal: the database accepts exactly `getEnabledWorkKinds()`.
- Tests that assumed perfumes were closed now assert the open state: `domain-navigation.test.ts` (Perfumes in the sidebar, `G E` and `A E`, the `/perfumes` layout lets requests through; films and paintings still 404) and `work-kinds.test.ts`.
- `book-domain-isolation.test.ts`: a taxonomy family's card counts the records of every open collection, so a subject on one book and one perfume now counts 2. Its items still count books only (see Completion Notes).
- Docs: `docs/02_DATA_MODEL.md` (work domains, perfume and film sections), `docs/04_ROUTES_AND_VIEWS.md`, `docs/14_CURATED_LIBRARY_PLAN.md`.
